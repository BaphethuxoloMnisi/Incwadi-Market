# Incwadi-Market
Overview
Incwadi Market is an Android mobile application developed to help students buy and sell second-hand academic textbooks within higher education institutions. The application provides a decicated marketplace where students can access affordable learning resources and connect directly with other students.

Project Purpose
The purpose of this application is to reduce the financial burden associated with purchasing academic textbooks by creating a student-focused marketplace where textbooks can be bought and sold at affordable price.

Target Users
University students, college students, students seeking affordable textbooks and students wishing to sell unused textbooks.

Features
User registration and login, browse available textbooks, search textbooks by title and author, view detailed textbook information, contact sellers through messaging, user profile management and structured navigation between screens.

Technologies Used
Kotlin, XML layouts, Android Studio, RecyclerView, View Bidning, Material Design Components and GitHub Version Control

Application Workflow
1. Launch the Application
2. Register or login
3. Browse Available Textbooks
4. Search for specific books
5. View book details
6. Contact the seller
7. Complete the interaction
